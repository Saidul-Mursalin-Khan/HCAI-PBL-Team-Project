Study overview

Same movies. Different ways to express taste.

01

Choose between two

Select the movie you would rather watch. Ten choices train a Bradley-Terry preference model.

02

Rank a set of ten

Order every movie from most to least preferred. A Plackett-Luce model learns from the full ordering.

03

Validate both models

New choices evaluate both methods fairly. Validation answers never update either model.
